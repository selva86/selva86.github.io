A note from the desk, on the order that works

Most people fail at R not because it's hard, but because they start in the wrong place. They jump to machine learning before they're comfortable with a data frame, hit a wall, and decide R "isn't for them." It was never R. It was the order.

So I sequenced these routes the way I'd teach them across a table: get fluent with the data structure first, learn to bend messy data to your will, then reach for the fancy stuff. Every stage below exists because the one after it needs it. Skip ahead if you must, but the line is drawn for a reason.
