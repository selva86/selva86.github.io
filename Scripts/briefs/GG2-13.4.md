This chapter is a CAPSTONE PROJECT, not a tutorial: build a complete,
publication-grade FIGURE SYSTEM for one real analysis, end to end, at the
standard a journal submission or a data-team style guide demands.

Mandatory arc (top-level sections, real code, real rendered outputs):
1. THE ENGAGEMENT: a realistic study (pick one real dataset with several
   findings, e.g. palmerpenguins or a gapminder slice) that needs a
   coherent SET of 5-6 figures for a paper: main result, comparison,
   distribution, model output, supplementary.
2. AUDIT THE DEFAULTS: render the naive default versions first and critique
   them honestly - what a reviewer would flag.
3. THE SYSTEM: build one theme + one palette + shared scales as reusable
   functions; every subsequent figure uses them. Type, spacing, grid and
   legend decisions each justified in a sentence.
4. THE FIGURES: construct each of the 5-6 figures step by step, each with a
   caption written as it would appear in the paper.
5. UNCERTAINTY SHOWN PROPERLY on at least two figures (intervals or
   distributions, not bare bars).
6. EXPORT: exact ggsave/device settings for the target journal spec (mm
   sizes, DPI, vector vs raster), file naming, and a reproducibility note.
7. THE HANDOFF: the complete figure-system code in one final runnable block
   a reader can lift into their own project.
Presentation: no output without interpretation; every design choice earns a
reason; figures must be visibly better than the part-2 defaults.
