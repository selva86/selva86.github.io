# Logo sources

in the real signup-domain table for r-stats-prod, so the claim the
strip makes (people have signed up from here) is true. The marks are
the property of their owners and are used to say where learners come
from, not to imply any endorsement, sponsorship or affiliation.

Files added 2026-11-11, from Wikimedia Commons, sanitised before use
(no script, no foreignObject, no event handlers, no external refs).

## Not used

- Tsinghua University: the only Commons SVG is a 423 KB circular seal,
  wrong shape for a wordmark strip.
- George Washington University: stacked lockup, illegible at strip height.
- Wisconsin, and first attempts at Virginia Tech and Maryland: fuzzy
  search returned a Wikipedia Education Program logo, an ACC conference
  badge and an NCAA sports mark. Virginia Tech and Maryland were then
  found correctly by exact filename; Wisconsin was not, so it stays a
  wordmark.

If any institution asks for its mark to be removed, delete the file and
its row from the strip in index.html; the name alone is still accurate.
