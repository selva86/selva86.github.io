Part 12 The thirty objections

  1. Normality was not assessed
  2. Equal variance was not checked
  3. Observations are not independent
  4. Residuals are autocorrelated
  5. Multicollinearity was not examined
  6. Linearity was assumed rather than shown
  7. The proportional hazards assumption was not tested
  8. No power analysis and no sample size justification
  9. Confounding was not addressed
  10. Baseline differences between groups were not adjusted for
  11. Selection bias and non-response were not discussed
  12. The control group is not comparable
  13. Multiple comparisons were not corrected
  14. Subgroup analyses were not pre-specified
  15. A p-value of 0.049 is treated as a finding
  16. This looks exploratory rather than confirmatory
  17. A continuous variable was dichotomised without justification
  18. Outliers were removed without a stated rule
  19. p-values are reported without effect sizes
  20. Confidence intervals are missing
  21. A non-significant result is described as a trend
  22. Model fit statistics are not reported
  23. Missing data handling is not described
  24. A parametric test was used on ordinal data
  25. A mixed model should have been used
  26. The link function or error distribution is not justified
  27. Zero-inflation was not considered
  28. There are too many predictors for the sample size
  29. An interaction is claimed without testing the interaction term
  30. Code and data are not available
