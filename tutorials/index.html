5 tutorials · about an afternoon

Not a dumped table of contents. These five, in this order, are the ones I'd sit a friend down with. Each one earns its place.

R Syntax 101 →

Twenty minutes that save you twenty hours of squinting at error messages. The grammar first, so everything after it reads instead of mystifies.

R Vectors →

Start here even if you think you know vectors, most beginner bugs trace back to recycling and coercion happening quietly behind your back.

Learn R beginner 9 min read
# R recycles the short one. surprising? read on. c(1, 2, 3, 4) + c(10, 20) #> 11 22 13 24
 3

R Data Frames →

The table at the heart of every analysis you'll ever run. Get comfortable here and half of data wrangling stops feeling like wrangling.

Learn R beginner 12 min read
# a data frame is just named columns of equal length df <- data.frame(name = c("a","b"), n = c(1, 2))
 4

dplyr: filter & select →

The first two verbs of the tidyverse, and the two you'll reach for most. Slice the rows you want, keep the columns you need, readably.

Data Wrangling beginner 11 min read
# read it like a sentence mtcars |> filter(mpg > 25) |> select(mpg, wt)
 5

ggplot2: The Grammar of Graphics →

Once this clicks you stop memorizing chart recipes and start composing them. It's the single highest-leverage idea on the whole site.

Visualization beginner 22 min read
# data + mapping + layer = any chart ggplot(mtcars, aes(wt, mpg)) + geom_point()
The fastest way to understand a model is to change one input and watch the output move.
