iNew to A/B testing? Read the 4-minute primer

What it is. Route traffic to two variants, measure a binary outcome, ask whether B’s true rate differs from A’s or it’s sampling jitter.

How to read it. Lift = B−A. p = chance of a gap this big under no difference. A 95% CI crossing zero can’t rule out “no effect”. BF10 > 10 favours B.

Frequentist vs Bayesian. Frequentist sets alpha + power, decides on p. Bayesian updates a prior to a Beta posterior, reports P(B>A) + a credible interval.

Picking the mode. Not run yet → Plan (baseline, MDE, power → sample size). Done → Analyze (per-arm visitors + conversions).

Plain-English inference

We compared your two groups using a two-proportion z-test (frequentist) and a beta-binomial Bayesian model side by side. B’s rate of 14.40% is 2.40pp higher than A’s 12.00%. Frequentist: the difference is not statistically significant (p = 0.1129, 95% CI [−0.57, 5.37]pp). Bayesian: there is a 94.5% probability that B beats A.

Reproduce in R runnable 
# Frequentist: two-proportion z-test
prop.test(c(120, 144), c(1000, 1000), correct = FALSE)

# Bayesian beta-binomial (Beta(1,1) prior)
set.seed(42)
post_a <- rbeta(1e5, 121, 881); post_b <- rbeta(1e5, 145, 857)
mean(post_b > post_a)                    # P(B>A)
quantile(post_b - post_a, c(.025, .975)) # 95% CrI

Anatomy of an A/B test the math, 5 steps
p_pool=(c_a+c_b)/(n_a+n_b) SE_0=sqrt(p_pool(1-p_pool)(1/n_a+1/n_b)) z=(p_b-p_a)/SE_0 ; p=2(1-Φ(|z|))
Two-proportion z-test. Pool under H0, compute SE, read z. CI uses the unpooled SE. Matches prop.test(...,correct=FALSE).
prior Beta(α₀,β₀) → posterior Beta(α₀+c,β₀+n-c) output P(p_b>p_a), 95% CrI
Beta-Binomial conjugate. Posterior is Beta in closed form. Sample 10,000 draws, count P(B>A), take 2.5/97.5 percentiles of the lift.
interim look at fraction t of N; spend α_t, sum=α (Pocock)
Sequential alpha-spending. Peeking K times and stopping early inflates false positives; Pocock / O’Brien-Fleming spread alpha across looks.
h=2(arcsin√p2-arcsin√p1); n=(z_α+z_β)²/h²
Sample size for proportions. Arcsine transform (Cohen’s h). n per arm at 50/50; scale by 1/(4k(1-k)) for unequal. Matches pwr.2p.test().
absolute=p_b-p_a; relative=(p_b-p_a)/p_a; RR=p_b/p_a
Lift vs RR vs absolute. 10%→12% is +2pp absolute, +20% relative, RR=1.20. CIs/BF10 on the absolute scale.
When this is the wrong tool 6 alternatives
If you have…
Use instead
Three or more variants
Multi-armed bandit (Thompson sampling), or Bonferroni / Holm over pairwise z-tests.
Continuous outcome (revenue, time)
Welch’s two-sample t-test. The two-proportion test forces a binary outcome.
Survival / time-to-event
Kaplan-Meier + log-rank, or Cox proportional hazards. Censoring breaks the binomial.
Repeated measures on same user
Paired test (McNemar / paired t), or mixed-effects with user random intercept.
Ratio metrics (clicks-per-visit)
Delta-method or bootstrap CI. The denominator is random per user.
You peeked early & stopped
Group-sequential (alpha-spending) up front, or always-valid intervals (mSPRT).
