How every lesson is made

The rigour is the product. Four rules every page on the site has to pass before it ships.

01

Taught from the ground up

Intuition first, then a simulation you can run, then the mathematics, then the code. No step is skipped and no leap goes unexplained.

02

Run, not pasted

Every output you see on a page was produced by running that code. If the numbers on the page and the numbers in your console ever differ, that is a bug we fix.

03

Checked before it ships

Exercises are auto-graded against real output. Each lesson passes a quality gate for gaps, misconceptions and broken links before it is published.

04

Referenced, and corrected

Every method cites three to five authoritative references. Reply to any lesson and a person reads it; corrections go live the same week.

Every page carries a verification line with the R version it was last run on.

How do I learn statistics and ML?

Pick one tool and spend most of your time running methods on real data, not watching videos. Follow a structured path, build real projects along the way, and practice daily.

  1. 01
    Pick one tool and stick with it.R is a great first choice for this: the statistics are first-class, and every method you will ever read about ships with an implementation.
  2. 02
    Follow a structured path.Random tutorials leave gaps. A linear roadmap removes the "what should I learn next?" problem entirely.
  3. 03
    Run something every day.Understanding is a skill that takes real time. Daily practice beats occasional binge-sessions.
  4. 04
    Work on real data.Real data has gaps, outliers and surprises. Projects force you to handle them, and they become the portfolio that gets you interviews.
  5. 05
    Get unstuck fast.Everyone gets stuck. Lean on a hint ladder that asks questions, and a human who answers when you reply.
  6. 06
    Go deep on one specialty.Once you have the foundations, specialise. Bayesian methods, causal inference, time series, machine learning. Pick one and go deep.

Frequently asked questions

Got questions? We've got answers

Can I sign up and try r-statistics.co for free?

Yes. It is free to create an account and start learning. The first section of every track is free, with graded exercises, and so are all 1,800 tutorials, the three handbooks and the tools.

How do I teach myself statistics?

Run the methods on real data, in order, every day. The tracks here are that order. Each page teaches one idea, runs the code in front of you, and then checks that you can do it yourself.

Can I learn statistics and ML on my own?

Yes, and most people here do. What you need is a structured path so you never wonder what comes next, feedback when you are wrong, and someone to ask when you are stuck. All three are built in.

How long does it take?

About three months per track at three hours a week. The daily five-minute email lesson keeps the thread between sessions.

Can I learn for free?

Yes. The first section of every track, the whole tutorial library, the handbooks and the tools stay free. Pro unlocks the rest of all six tracks (about 630 lessons), every certificate, and the portfolio projects.

Hasn't AI made learning statistics obsolete?

AI can write the code. It cannot tell you whether the answer is right, whether the test fits the question, or whether the model is lying to you. That judgement is the job, and it is what these tracks teach.

Should I include the projects in my resume and portfolio?

Yes. Each track ends in a graded portfolio project on real data, and each certificate has a public verification page you can send to an employer.

What is r-statistics.co? A bootcamp? An online school?

An online learning platform for statistics and machine learning, taught through R. Interactive lessons, graded practice, and certificates, with a free library that has been around since 2015.

What makes r-statistics.co different?

Every method is explained from the ground up and run live in your browser, with the statistics underneath the model rather than just the buttons to press. Progress is graded, not watched.
