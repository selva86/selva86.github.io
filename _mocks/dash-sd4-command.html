Design notes: what moved, what's new, what's gone
  • Organizing idea: everything on one screen, zero scroll for the returning power user. Three columns with a strict grammar: act (left), progress (middle), library and sell (right). The header band fuses hello + stats so the numbers stop costing vertical space.
  • Kept: every live element, none dropped: set with bonus, reading + open-lesson windows (In flight), tracks all seven, certificates AND badges unified in one credential card, catalog condensed to rows (the Pro wall preserved per owner rule), saved, upsell/Team slot, streak chip, meter tile flag-gated, opt-in logic unchanged.
  • New: review queue, weekly recap mini, freezes in the header line, expiring-lesson alert in the header, badges beside certificates.
  • Gone: "Recommended next" and the tall reading-resume hero (its content lives in the compact In-flight rows; the hero slot goes to the single most valuable action).
  • Trade-off: density costs warmth; new users with empty states would see a sparse grid, so the empty-state design (?start mode) matters most in this variant and should fall back to an SD1-style welcome.
