dplyr filter() in R: Subset Rows by Condition

The filter() function keeps rows that satisfy a logical condition and drops the rest. Combine conditions with &, |, ! or list them as separate arguments (treated as AND).

What filter() does in one sentence

It returns the rows of a data frame for which a logical condition is TRUE, dropping rows where the condition is FALSE or NA. That's the entire mental model — everything else is just how you write the condition.

library(dplyr)

# Single condition
filter(mtcars, mpg > 20)

# Multiple AND conditions (comma-separated)
filter(mtcars, mpg > 20, cyl == 4)

# OR — use single |
filter(mtcars, mpg > 20 | cyl == 4)

NA-safe filtering — the trap everyone hits

Comparisons against NA return NA, and filter() drops NA rows by default. If you mean "keep rows where x is greater than 5 OR missing", you must say so explicitly: filter(df, is.na(x) | x > 5).

Filter by group with .by

Since dplyr 1.1 you can group inline without group_by(). To keep the row with the highest mpg per number of cylinders:

filter(mtcars, mpg == max(mpg), .by = cyl)
