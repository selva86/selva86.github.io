Concept

The six basic types

Every value in R is exactly one of six types. One call to class() names it. Each type gets its own colour, you'll see them everywhere from here.

numeric integer character logical complex raw

The literal you write decides the type. A decimal is numeric, an L makes an integer, quotes make character.

Concept

Checking a type in code

class() names the type; the is.*() family tests for one and returns TRUE or FALSE, perfect inside an if.

Check yourself

Quick question

What does is.numeric("72.5") return?

Exactly. Anything in quotes is character, even "72.5". That is why one stray quote in a CSV column breaks your math.
Not quite. The quotes win: "72.5" is character, so is.numeric() is FALSE.
Concept

class() vs typeof()

class() is what an object acts like; typeof() is how R stores it. They differ more often than you'd think.

Key insight

A data frame has class "data.frame" but typeof "list", because it is a list of columns inside. Knowing this is how you debug "why doesn't my function work on this object?"

Concept

Why "5" is a double

Every bare number is a double unless you add L. Integers are compact but overflow near 2.1 billion; doubles go far higher.

Tip

Reach for L only when you have millions of counts and memory matters. Otherwise let R default to double, one fewer surprise.

Concept

NA, NULL, NaN, Inf

Four "missing-ish" values that behave very differently: NA (missing, length 1), NULL (nothing, length 0), NaN (0/0), Inf (1/0).

Warning

is.na(NULL) returns logical(0), not FALSE, which can crash an if. Use is.null() for NULL and is.na() for NA. Never mix them up.
