Which type is your variable?

R has six basic data types, and the type of a value quietly decides what you can do with it. Get it wrong and your math turns into string concatenation.

The six basic types

Every value in R belongs to exactly one of six basic types. One call to class() tells you which, and from here on, each type gets its own colour.

numeric integer character logical complex raw

The literal you write decides the type. 72.5 has a decimal, so numeric. 30L carries the L, so integer. Quotes make "Selva" character. Try your own values in the inspector above, that is the whole game.

When types collide: coercion

R won't let different types share a vector. Mix them and it silently coerces everything up one ladder, and the highest type wins. Build a vector below and watch it happen.

Coercion Mixertap values to add them
Warning

Coercion is silent, which is what makes it dangerous. One stray "three" in a column of numbers turns the whole thing to character, and sum() breaks with no warning. When a result looks wrong, class() your inputs first.

"One bad cell contaminates the whole vector."

Which type, when?

The choice is usually obvious. Text is character; TRUE/FALSE is logical; a whole number that never nears two billion is integer; everything else is numeric.

TypeExampleWhen to use
numeric72.5Default for any number, measurements, money
integer30LCounts, IDs, saves memory at scale
character"Selva"Any text, names, labels
logicalTRUEFlags, comparisons, filters
