Filter & subset rows

14 recipes  ·  Beginner
filter() Subset rows by condition

Keep rows that satisfy a logical condition. Covers AND/OR, %in%, between(), NA-safe filtering, .by grouping.

Beginner7 examples
distinct() Remove duplicate rows

Drop duplicate rows by all columns or a chosen subset; use .keep_all to preserve every column.

Beginner
slice() Pick rows by position

Select rows by integer index or negative position. The base for slice_head/tail/min/max/sample.

Beginner
slice_max() Top N rows by value

Return the N rows with the largest values of a chosen column, optionally within groups.

Beginner
slice_sample() Random sample of rows

Take a random sample of N rows or proportion of rows; supports weighted sampling and grouping.

Beginner
slice_head() First N rows per group

Get the first N rows overall or within each group. Faster and clearer than head() inside group_by.

Joins & set operations

14 recipes  ·  Beginner → Intermediate
left_join() Keep all rows of x, attach y

The most common join. Keeps every row of the left table and fills missing matches with NA.

Beginner
inner_join() Keep matched rows only

Returns only rows that match in both tables. Use when missing matches must be excluded.

Beginner
anti_join() Rows in x without match in y

The "missing from lookup" join. Returns rows of x that do NOT have a match in y.

Intermediate
semi_join() Filter x by membership in y

Like filter() with a lookup table. Returns rows of x that match y, without adding y's columns.

Intermediate
join_by() Non-equi & rolling joins

Join on inequalities, ranges, or rolling conditions — not just equality.

Intermediate
cross_join() All combinations of x and y

Cartesian product. Useful for generating parameter grids or all-pairs comparisons.

Intermediate

Shift a column forward or back to compute differences, growth rates, and gaps.

Intermediate
cumsum() & friends Running totals & averages

Cumulative sum, mean, min, max — combine with group_by() for running stats per group.

Intermediate

Assign 1..N to rows within each group, after arrange(). The simplest ranking function.
