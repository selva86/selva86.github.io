R Data Types: Which Type Is Your Variable?

R has six basic data types, numeric, integer, character, logical, complex, and raw, and the type of a value quietly decides what you can do with it. Get it wrong and your math turns into string concatenation, or your model silently drops rows.

What are R's six data types?

Before you can trust a number, you need to know whether R actually sees it as a number. Every value in R belongs to exactly one of six basic types, and one call to class() tells you which.

Six values, six types. weight is numeric because 72.5 has a decimal. age is integer only because of the L suffix, without it R would store 30 as numeric too. name is character (always quoted). The literal you write decides the type.

How does R coerce types automatically?

R won't let values of different types sit in one vector, everything in c(...) must share a single type. When you mix them, R silently coerces everything up a strict ladder: logical, integer, double, complex, character. Character always wins, because any value can be written as text.

That single "three" turned 1 and 2 into the strings "1" and "2", and sum() now errors. This is the single most common "my CSV won't add up" bug in R: one stray cell makes the whole column character.

Warning

Coercion is silent, which is what makes it dangerous. R won't warn you that your numbers became strings, you only find out when arithmetic breaks downstream. When a result looks wrong, class() your inputs first.

Which type should I use when?

With six types the choice is usually obvious. If it's text, use character; TRUE/FALSE is logical; a whole number that never nears two billion is integer; otherwise use numeric. Complex and raw are specialist types you'll know when you need.

TypeExampleclass()When to use
numeric72.5"numeric"Default for any number, measurements, money
integer30L"integer"Counts, IDs, indexes, saves memory at scale
character"Selva""character"Any text, names, labels, categories
logicalTRUE"logical"Flags, comparison results, filter masks
complex1 + 2i"complex"Signal processing, rare in stats work
rawas.raw(255)"raw"Binary files, bytes, specialist use
Tip

Prefer character over factor for free-text columns. Use character as the default and convert to factor only when you genuinely need ordered levels for modeling or plotting.
