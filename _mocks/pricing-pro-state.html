Three rules that go with the page

1. Where the buttons go

Signed out: every plan button goes to sign-in and comes back here, exactly as today.

Signed in: plan buttons open checkout directly. Manage billing opens the Paddle billing portal the account page already mints (card, invoices, cancel). Upgrade to All-Access changes the existing subscription in place, prorated, instead of starting a second one.

A Pro member who lands here from a lesson wall or an old link sees Your plan. and a way back, never a checkout.

2. Roadmap rows for Pro members

Today an unbuilt Pro item on the Researcher, Forecaster and R Developer roadmaps links to this page for everyone, members included. For a Pro viewer it becomes a plain Soon row, the way the Data Scientist roadmap already shows unbuilt items.

3. No flash on Pro lessons

Pro status is read from the same signed sign-in cookie the edge uses, so the page knows the plan on first paint. The This is a Pro module card no longer appears for a second and vanishes.

If the browser has a session but the edge served the locked version (an expired cookie), the player shows a plain loading skeleton and reloads once, instead of the wall.
