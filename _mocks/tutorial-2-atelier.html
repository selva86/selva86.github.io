Which type is your variable?

The six basic types

Before you can trust a number, you need to know whether R actually sees it as a number. Every value in R belongs to exactly one of six basic types, numeric, integer, character, logical, complex, and raw, and a single call to class() tells you which one you are holding.

Six values, six types. weight is numeric because 72.5 has a decimal. age is integer only because of the L suffix. The literal you write decides the type, no exceptions.

In the margin

Without the L, R would store 30 as a double too. The L is the only thing that makes an integer literal.

How R coerces types automatically

R will not let different types share a vector. When you mix them, it silently coerces everything up a strict ladder, logical, integer, double, complex, character. Character always wins, because any value can be written as text.

That single "three" turned 1 and 2 into strings, and sum() now errors. It is the most common "my CSV will not add up" bug in R, and because coercion is silent, you only discover it downstream.
