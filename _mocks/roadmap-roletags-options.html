Hero role tags: four options + the integrated best

The current tags read like generic filter chips, lighter than the rest of the page. Below: the baseline, four directions each rendered with the real six roles, and the recommended integrated version at the end. All in the F2 system.

BASELINEwhat is on the page now
Flat pills, dot + label. Problem: reads as tags/metadata, no hierarchy, no preview of what each role is, no sense of the core-vs-branches structure.
OPTION Arefined tinted pills
Pros: minimal change, fast, each role tinted in its own colour, satisfying hover fill. Cons: still fundamentally chips; does not preview the role or show the core-vs-track split. Incremental, not a step-change.
OPTION Bsegmented track switcher
Pros: feels like a real, premium UI control; the connected bar reads as one object; the core/then-specialize gap encodes structure; can double as anchor-nav. Cons: six segments get cramped on mobile (wrap looks broken); a segmented control implies single-select, which the roles are not.
OPTION Crole tiles
Pros: each role gets a name + a one-line "what you do" + colour bar + arrow; previews and navigates to each role page; substantial, clearly premium. Cons: heavier in the hero, competes with the headline for attention, uses more vertical space.
OPTION Dpath / branch
Pros: most on-brand: it mirrors the timeline below and tells the "two shared steps, then four equal branches" story at a glance, right in the hero. Cons: busiest layout, the hardest to keep clean on small screens, more of a diagram than a nav.
RECOMMENDEDintegrated
Why this one: it fuses C's preview-tiles with D's structure. Two labelled groups make the "shared core, then choose a track" thesis instantly legible (the whole point of the redesign), each role is a compact tile that previews its outcome and links to its page, and the colour lives in a single dot so the row stays calm. It elevates the tags from metadata to a curated set of paths, scales cleanly to mobile (groups stack), and matches the page's card + mono-label language. Lighter than full C tiles, clearer than D.
