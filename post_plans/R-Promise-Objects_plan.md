## E. Section outline

### Core H2 sections (6 total)

#### 1. What is a promise object in R?
- **Theory:** Three slots (expression, environment, value). Unused args never run.
- **Block 1 (payoff):** `show_when(a, b)` — b is a noisy `cat()` expression that never prints.
- **Callout KEY INSIGHT:** A promise is R's IOU for a value — expression + environment + empty slot that fills on first use.
- **Inline exercise:** Write `ex_lazy(x, y)` returning `x * 2`; pass a noisy `y` and confirm it stays quiet.

#### 2. How does lazy evaluation actually work step by step?
- **Theory:** The 4-step lifecycle — wrap in promise → bind to formal → force on first access (cache) → subsequent accesses return cached value.
- **Block 2:** `use_twice(x)` where `x = noisy()` with a global counter; show `counter = 1` even though `x` is used twice.
- **Callout TIP:** "Evaluate once, cache forever" is why lazy evaluation doesn't slow your code down.
- **Inline exercise:** Predict counter after calling a function that uses `x` three times.

#### 3. Why do default arguments see other function arguments?
- **Theory:** Default args evaluate inside the *function's* environment; caller-supplied args evaluate in the *caller's* environment. That's why `function(x, n = length(x))` works.
- **Block 3:** `smart_default(x, n = length(x))` — call with and without `n`.
- **Block 4:** The `h05()` trap — `function(x = ls())` behaves differently when user supplies `ls()` vs. takes the default.
- **Callout KEY INSIGHT:** Default = lazy + function's env. Caller-supplied = lazy + caller's env. Two different worlds.
- **Inline exercise:** Write `ex_append(x, suffix = paste0("-", length(x)))` and test.

#### 4. What is the closure-loop trap and how does force() fix it?
- **Theory:** When a function factory captures a loop variable via a promise, every returned closure ends up pointing at the same (final) binding. `force()` evaluates the promise eagerly so each closure captures its own value.
- **Block 5:** Buggy `make_adder(n)` built inside a `for` loop — all adders return 13.
- **Block 6:** `make_adder_safe(n)` with `force(n)` — adders correctly return 11, 12, 13.
- **Callout WARNING:** Function factories used inside loops must `force()` their captured arg. Silent bug, top-5 R gotcha.
- **Inline exercise:** Fix a buggy `ex_make_greeter(name)` factory by adding `force()`.

#### 5. How does substitute() let you inspect a promise?
- **Theory:** `substitute()` peeks at the expression slot without forcing the promise. This is the entry point to metaprogramming: it's how `plot()` labels axes, how `curve()` takes `sin(x)` unevaluated, how dplyr treats bare column names.
- **Block 7:** `show_expression(expr)` prints both the deparse'd expression and the value.
- **Callout NOTE:** `substitute()` only captures the promise at *its own* argument position. If you forward the argument, `substitute()` in the nested function sees only the forwarded symbol.
- **Inline exercise:** Write `ex_describe(x)` that returns a named list with `expression` and `value`.

#### 6. Can I create promises manually with delayedAssign()?
- **Theory:** `delayedAssign("name", expr, eval.env, assign.env)` creates a top-level promise bound to `name`. Used for expensive package datasets loaded on first touch.
- **Block 8:** `delayedAssign("big_calc", {...})` — prints "Calculating..." only on first access; second access returns cached value silently.
- **Callout TIP:** For *re-computed* values (not one-shot promises), reach for `makeActiveBinding()` instead.
- **Inline exercise:** Use `delayedAssign()` to create `ex_config` that reads from a simulated source only when touched.

#### 9. Summary (table)
| Concept | What it is | When you notice it |
| --- | --- | --- |
| Promise | expression + environment + value slot | Every function call |
| Lazy evaluation | Delay compute until first use | Unused args never run |
| `force(x)` | Evaluate a promise now, cache result | Function factories |
| `substitute(x)` | Read expression without forcing | Metaprogramming |
| Default arg trap | Default uses function's env | `function(x = ls())` surprise |
| Closure-loop trap | All closures share one promise | `for` + function factory |
| `delayedAssign()` | Manual top-level promise | Package datasets |
