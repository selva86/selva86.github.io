## C. Full Section Outline

### Lead Paragraph
Every VLOOKUP, pivot table, IF formula, filter, sort, and chart you use in Excel has a direct one-line equivalent in R — and this guide maps each one, with runnable code you can edit in place.

### First H2 Opening Prose (≤80 words)
AutoFilter and Sort are where Excel users spend their mornings. In R, both collapse into one readable line per operation. You don't click a dropdown, tick boxes, and lose the state next time the file opens — you write `filter()` and `arrange()` once, and the same logic runs every time on any dataset with the same columns. Here is the exact translation, running on a small sales dataset we will reuse throughout.

### Core H2 Sections (6)

#### H2-1: How do you replace Excel's AutoFilter and sorting in R?
- Theory: `filter()` replaces AutoFilter dropdowns; `arrange()` replaces Sort A-Z / Z-A
- Code block 1 (PAYOFF): library calls, create `sales` tibble, filter East region + quantity > 5 — visible filtered output
- Code block 2: arrange by quantity (desc) — sorted output
- Callout: [KEY INSIGHT] `filter` chooses rows, `arrange` reorders them — two verbs, one grammar; unlike Excel, both are re-runnable.
- Inline exercise: filter West region with quantity ≥ 10

#### H2-2: How do you write Excel formulas as R columns?
- Theory: `mutate()` adds calculated columns; `if_else()` / `case_when()` replace =IF and nested IFs
- Code block 3: mutate revenue = quantity * unit_price, total_with_tax = revenue * 1.08
- Code block 4: case_when for revenue tier (Low/Med/High) — replaces nested IF
- Callout: [TIP] case_when reads top-to-bottom — the first match wins, exactly like a nested IF.
- Inline exercise: write case_when that labels quantity as "Bulk" if >10 else "Single"

#### H2-3: How do you replace VLOOKUP with R joins?
- Theory: VLOOKUP looks up a key in another table; `left_join()` does the same — safer, supports multi-column keys, preserves row order
- Code block 5: create `product_info` lookup (product, category, brand), left_join to attach category and brand — show the extra columns appear
- Show unmatched-key behavior — NA row = Excel's #N/A
- Callout: [WARNING] Duplicate keys in the lookup inflate rows silently. Run `distinct(product_info, product, .keep_all = TRUE)` first if you want VLOOKUP's "first match only" behavior.
- Inline exercise: left_join a `region_manager` lookup on region

#### H2-4: How do you build a pivot table in R?
- Theory: group_by + summarise = the Values box; pivot_wider = the crosstab layout with regions/products as rows/columns
- Code block 6: group_by(region) + summarise(total_revenue, orders = n()) — SUMIF + COUNTIF in one shot
- Code block 7: group_by(region, product) + summarise(total = sum(revenue)) + pivot_wider — full region × product crosstab
- Callout: [KEY INSIGHT] Pivot table = group_by (drag-to-rows) + summarise (Values) + pivot_wider (drag-to-columns). Three verbs, no mouse.
- Inline exercise: count orders per region using group_by + summarise

#### H2-5: How do you reshape Excel data without copy-paste?
- Theory: pivot_longer = Unpivot / Get & Transform; `separate_wider_delim()` = Text to Columns
- Code block 8: create a wide quarterly frame (Q1..Q4 columns), pivot_longer to long format
- Code block 9: split a "Region-Product" text column into two columns with separate_wider_delim
- Inline exercise: pivot_longer a 2-month wide table

#### H2-6: How do you replace Excel charts and conditional formatting?
- Theory: ggplot2 replaces Excel charts; `scale_fill_gradient()` (or `gt`) gives the colored-by-value effect of conditional formatting
- Code block 10: ggplot bar chart of total revenue by region
- Mental mapping: data → `aes()` → `geom_*` → chart
- Callout: [NOTE] Plots render directly in the output area below the block. No PNG export needed for learning.
- Inline exercise: build a bar chart of revenue by product
