## C. Full Section Outline

### Lead Paragraph
"R for Excel users is a practical mapping of every common spreadsheet operation — filtering, sorting, VLOOKUP, pivot tables, IF formulas, and charts — to its R equivalent using base R, dplyr, tidyr, and ggplot2."

### Introduction (## Introduction)
- Hook: You already think in data — Excel taught you that. R just gives you a more powerful language for the same operations.
- What: This guide maps the Excel operations you already know to their R equivalents.
- Why: R handles millions of rows, automates repetitive tasks, and produces publication-quality charts — all things Excel struggles with.
- What you'll learn: filtering, sorting, formulas, VLOOKUP, pivot tables, IF logic, text functions, reshaping, conditional formatting via ggplot2, and a complete end-to-end workflow.
- Package note: We use dplyr, tidyr, and ggplot2 — all run directly in your browser here.

### Core H2 Sections (7 sections, all question-form)

#### H2-1: How Do You Filter and Sort Data Like Excel's AutoFilter?
- Theory: Excel AutoFilter = dplyr::filter() + arrange()
- Code block 1: Load libraries + create sample sales data (simulating an Excel spreadsheet)
- Code block 2: Filter rows by condition (like clicking AutoFilter dropdown)
- Code block 3: Sort by one or multiple columns (like Sort A-Z)
- Callout: [TIP] filter() returns all matches; Excel AutoFilter hides non-matching rows
- Inline exercise: Filter sales data to find orders above $500 in the "West" region

#### H2-2: How Do You Create Calculated Columns Like Excel Formulas?
- Theory: Excel formula in a new column = dplyr::mutate()
- Code block 4: Add calculated columns (profit margin, tax amount) with mutate()
- Code block 5: Conditional columns — ifelse() as R's IF() function
- Callout: [KEY INSIGHT] In Excel, formulas recalculate automatically. In R, you run mutate() once and the column is stored — no circular references possible.
- Inline exercise: Create a column that flags orders as "High" or "Low" based on quantity > 10

#### H2-3: How Do You Replicate VLOOKUP and INDEX-MATCH with R Joins?
- Theory: VLOOKUP = left_join(). INDEX-MATCH = left_join() with multiple keys.
- Code block 6: Create a lookup table (product categories)
- Code block 7: left_join() to bring in category — the VLOOKUP equivalent
- Code block 8: Handling the "approximate match" scenario and multiple-key joins
- Callout: [WARNING] VLOOKUP silently returns the first match. left_join() returns ALL matches — check for duplicates in your lookup table.
- Inline exercise: Join a region_info table to add region manager names to the sales data

#### H2-4: How Do You Build Pivot Tables with group_by and summarize?
- Theory: Excel Pivot Table = group_by() + summarise()
- Code block 9: Group by region, summarize total sales and average order value
- Code block 10: Multi-level grouping (region + product category) — like dragging two fields into Rows
- Code block 11: Pivot wider with tidyr::pivot_wider() to get the cross-tab layout Excel shows
- Callout: [TIP] Use across() to apply the same summary to multiple columns at once — like dragging several fields into Values.
- Inline exercise: Create a pivot table showing count and mean sales by product category

#### H2-5: How Do You Replace SUMIF, COUNTIF, and Other Conditional Functions?
- Theory: SUMIF/COUNTIF/AVERAGEIF = filter() + summarise(), or group_by() + summarise() with conditions
- Code block 12: SUMIF equivalent — sum sales where region == "East"
- Code block 13: COUNTIF equivalent — count orders by category
- Code block 14: Nested conditions (SUMIFS with multiple criteria)
- Callout: [NOTE] Excel has separate functions for each operation (SUMIF, COUNTIF, AVERAGEIF). R uses one pattern: filter the rows, then apply any summary function.
- Inline exercise: Calculate the average order value for orders placed in Q1 (months 1-3)

#### H2-6: How Do You Reshape Data Like Unpivot and Text-to-Columns?
- Theory: Unpivot = pivot_longer(). Text-to-Columns = tidyr::separate()
- Code block 15: Wide-to-long reshaping with pivot_longer() (unpivot)
- Code block 16: Long-to-wide with pivot_wider() (recreate a cross-tab)
- Code block 17: separate() to split a combined column (like Text-to-Columns)
- Callout: [KEY INSIGHT] Excel forces you to choose between wide and long format. R lets you reshape freely — pivot_longer() for analysis, pivot_wider() for presentation.
- Inline exercise: Reshape a wide quarterly sales table to long format

#### H2-7: How Do You Create Charts That Replace Excel's Conditional Formatting and Graphs?
- Theory: Conditional formatting = ggplot2 color scales. Excel charts = ggplot2 geom layers.
- Code block 18: Bar chart of sales by region (replacing Excel bar chart)
- Code block 19: Scatter plot with color coding by category (conditional formatting equivalent)
- Code block 20: Heatmap with color gradient (the closest to conditional formatting)
- Callout: [TIP] ggplot2 separates data, aesthetics, and geometry — change one without touching the others. Excel ties chart type to the data selection.
- Inline exercise: Create a bar chart showing total sales by product category, colored by region

#### Common Mistakes and How to Fix Them (3-5 mistakes)
1. Using = instead of == in filter() (assignment vs comparison)
2. Forgetting to ungroup() after group_by() (silent downstream bugs)
3. Joining on mismatched types (character vs numeric keys)
4. Using $ inside dplyr pipelines instead of bare column names
5. Expecting VLOOKUP's approximate match behavior from left_join()
