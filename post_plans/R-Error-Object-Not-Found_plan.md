## C. Section Outline

### Lead paragraph (featured snippet)

> `Error: object 'x' not found` means R searched every loaded package and the current environment but no variable, function, or dataset with that name exists. The object was never created, was misspelled, was defined in a different scope, or was wiped when the session restarted.

**H2-3: Cause 2 — Forgot to assign with `<-`: why did my data vanish?**
- Explain that expressions without assignment print and discard.
- Code block: `data.frame(x = 1:3)` without assignment → `exists("df_wrong")` is FALSE → fix with `<-`.
- Callout: [WARNING] `read.csv("file.csv")` with no assignment looks like it worked (prints rows) but saves nothing.
- Inline exercise: fix a `read.csv` line that's missing assignment.

**H2-4: Cause 3 — Package not loaded: how do I know where a function or dataset lives?**
- Explain attaching a package vs qualified `pkg::name`.
- Code block: reference `starwars` via `dplyr::starwars`, then `library(dplyr); head(starwars)`.
- Callout: [NOTE] `requireNamespace("dplyr")` tells you if it's installed; `"dplyr" %in% loadedNamespaces()` tells you if it's attached.
- Inline exercise: use qualified `::` syntax to access a function without attaching its package.

**H2-5: Cause 4 — Running code out of order: why a line that worked yesterday fails today?**
- Explain RStudio's run-from-cursor + partial-chunk pitfalls.
- Code block: define `raw_input` and then `summary(raw_input)` top-to-bottom so the fix is obvious.
- Callout: [TIP] Ctrl+Alt+B runs from the top of the script to the current line in RStudio.
- Inline exercise: reorder 3 scrambled lines so they run error-free.

**H2-6: Cause 5 — Different scope: why can't I see a variable defined inside a function?**
- Explain R's lexical scoping + the gap between local and global environments.
- Code block: function defines `local_mean` inside its body, caller tries to read it (error), then fix by returning a list.
- Callout: [KEY INSIGHT] functions see the environment where they were *defined*, not where they're *called*.
- Inline exercise: rewrite a function so its result is visible to the caller.

**H2-7: Cause 6 — Column name doesn't exist inside dplyr verbs: why is it an "object" error and not a column error?**
- Explain dplyr's non-standard evaluation (NSE) — bare column names are evaluated as objects in the data frame's scope first, global scope second.
- Code block: `filter(mtcars, MPG > 20)` → "object 'MPG' not found" → fix with the correct case.
- Callout: [WARNING] inside `filter()` / `mutate()`, unknown column names manifest as "object not found", *not* "column not found".
- Inline exercise: fix a `mutate()` call whose column reference is wrong.

**H2-8: Cause 7 — Environment cleared or session restarted: where did all my variables go?**
- Explain `rm(list = ls())` and Session → Restart R; re-running the script is the cure.
- Code block: create `df_work`, simulate a restart with `rm(list = "df_work")`, show `ls()` is empty for that name, then rebuild.
- Callout: [TIP] prefer `source("my_script.R")` or a Quarto notebook over hand-running so rebuilds are one command.
- Inline exercise: after `rm(list = ls())`, restore a variable by re-assigning it.
