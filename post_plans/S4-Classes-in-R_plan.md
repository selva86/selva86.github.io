## C. Full Section Outline

### Lead Paragraph

**S4 classes** are R's formal object-oriented system — they enforce typed fields (called *slots*), validate data on creation, and support multiple dispatch so a single generic function can choose different behavior based on the types of *several* arguments at once. If S3 is a handshake agreement, S4 is a signed contract.

### H2 1: What Are S4 Classes and Why Use Them Instead of S3?

**Opening prose (~70 words):** S3 classes are simple — you slap a class label onto a list and trust everyone to play nice. That flexibility is great until someone passes a character where you expected a number and nothing breaks until three functions later. S4 solves this with formal class definitions that enforce types at creation time. Let's see the difference in action.

**Theory/intuition:** S3 = informal (convention-based), S4 = formal (enforced). S4 key features: typed slots, validity checking, multiple dispatch. When to pick S4: shared packages, Bioconductor, complex hierarchies.

**Callout:** KEY INSIGHT — S4 catches type errors at object creation, not when you use the object three functions later.

### H2 5: How Do You Enforce Data Integrity With Validity Checking?

**Theory:** setValidity() attaches a validation function to a class. validObject() triggers it. Automatic on new(). NOT automatic on slot modification via @. Cross-slot constraints.

**Code blocks:**

**Callout:** KEY INSIGHT — Validity functions run automatically on new() and on explicit validObject() calls, but NOT on direct slot assignment with @. This is the #1 S4 gotcha.

### H2 6: How Do You Define S4 Generics and Methods?

### Tail: Summary

Key takeaways as a bullet list:
- setClass() defines formal classes with typed slots
- new() creates objects; write helper constructors for users
- @ accesses slots; use accessor functions instead
- setValidity() enforces cross-slot constraints
- setGeneric() + setMethod() define polymorphic behavior
- Method dispatch walks the inheritance chain
- Multiple dispatch is S4's unique power over S3
- Use S4 for packages, Bioconductor, complex type hierarchies
