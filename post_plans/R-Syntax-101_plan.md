### Common Mistakes and How to Fix Them
1. `=` vs `==`: assign vs compare
2. Case mismatch: `MyVar` ≠ `myvar`
3. Unclosed quote/paren → `+` prompt
4. Shadowing built-ins like `c <- 1`
5. `mean(x = 1:10)` vs `x <- 1:10; mean(x)` (= inside calls doesn't persist)
