## First H2 opening prose (≤80 words)

Heading: **What does "non-numeric argument to binary operator" mean in R?**

Opening prose: "R throws this error the moment an arithmetic operator — `+`, `-`, `*`, `/`, `^`, `%%` — sees an operand that isn't numeric. The value may print exactly like a number and still be a character string, a factor, or a date. The one-line diagnosis is `class()`: once you know what R thinks each operand is, the fix is usually a single conversion function."

### H2 #2 — How do you find the guilty column inside a data frame?

- Code: mini data frame with mixed classes; scan each way.
- Callout: `[TIP]` — `names(df)[!sapply(df, is.numeric)]` is the one-line culprit finder.

### H2 #3 — What hidden characters turn a numeric-looking column into text?

- Whitespace, currency `$`, thousand `,`, `N/A`, stray units, unicode minus.
- Code: raw vector demonstrates failure + `readr::parse_number()` as a one-call cleaner, plus `gsub` alternative.
- Callout: `[WARNING]` — a single bad value drags the WHOLE column to character.
- Inline exercise: clean a price vector with `$` and commas.

### H2 #4 — How do you fix the three common cause patterns?

- Pattern A: character → `as.numeric()`.
- Pattern B: factor → `as.numeric(as.character(x))`.
- Pattern C: messy strings → `parse_number()` or `gsub` + `as.numeric`.
- Code: one block applying all three patterns.
- Callout: `[WARNING]` — direct `as.numeric()` on a factor returns level indices, not labels.
- Inline exercise: fix a factor of scores and take the mean.
