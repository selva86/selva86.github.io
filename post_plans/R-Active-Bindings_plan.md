## Lead paragraph

An active binding is a variable that runs a function every time you read or write to it. Instead of storing a static value, the binding executes a getter (and optionally a setter) on access — like a computed property in object-oriented languages. You create them with `makeActiveBinding()` in base R, and R6 uses the same machinery for its `active` fields.

## Core content sections (5 core H2s)

### H2 #1 — What is an active binding in R?

- Theory: normal binding vs active binding. The binding is a name → function call, not name → stored value.
- **Payoff code block (Block 1):** `library()` minimal; `makeActiveBinding("now", function() Sys.time(), globalenv())`; access `now` twice with `Sys.sleep(0.1)` between. Output shows two different timestamps. Cleanup with `rm(now)`.
- Second block (Block 2): counter example. Hidden env, active binding increments each access. Show 3 calls → 1, 2, 3.
- [KEY INSIGHT] callout: the binding *is* the function call — every appearance of the symbol re-runs it.
- **Try it (1):** create `today_is` active binding that returns `Sys.Date()` each access.

### H2 #2 — How do you create read-only vs read-write bindings?

- Theory: R's rule — if the function takes zero arguments, the binding is read-only (assignment errors). If it takes one argument, the binding is read-write; reads pass no argument, writes pass the assigned value. Use `missing(value)` to branch.
- Code block (Block 3): read-only computed mean. Create a hidden env holding a vector, bind `data_mean` to a getter that computes `mean()`. Change the underlying vector, show the binding auto-updates.
- Code block (Block 4): read-write temperature converter. `temp_fahrenheit` reads/writes a Celsius value under the hood.
- [TIP] callout: keep the underlying state in a dedicated environment with `.` prefix names to mark it private.
- **Try it (2):** create a `cm_to_inches` active binding (read-only) that reads from a hidden `.cm` value.

### H2 #3 — How can active bindings validate assignments?

- Theory: bindings are a perfect place to enforce invariants — the setter becomes a gate.
- Code block (Block 5): `age` with validation — must be numeric, 0–150. Show a failing assignment wrapped in `tryCatch()` that prints the error and leaves the value unchanged.
- [WARNING] callout: validation only fires on assignment to the bound name; if the reader mutates the hidden state directly they bypass the gate.
- **Try it (3):** write a `positive_balance` active binding that rejects negative values.

### H2 #4 — How are active bindings used in R6 classes?

- Theory: R6's `active` field is a thin wrapper around `makeActiveBinding()`. Fields look like data but run functions.
- Code block (Block 6): `Rectangle` R6 class with `width`, `height` (regular fields) and `area` (active field computed on read). Create instance, print area, mutate width, print area again.
- [KEY INSIGHT] callout: R6 active fields solve the "stale derived attribute" bug — the computed value can never drift.
- **Try it (4):** add a `perimeter` active field to the Rectangle.

### H2 #5 — When should you avoid active bindings?

- Theory: active bindings have real costs. Every access is a function call, not a pointer lookup. Accidentally writing a binding-based loop variable in a hot path is a silent perf killer. Debuggers and error messages get noisier.
- Code block (Block 7): microbenchmark comparing 100,000 reads of a normal variable vs an active binding. Use `system.time()` or a simple `for` loop with `Sys.time()` deltas (WebR-friendly).
- [WARNING] callout: active bindings aren't free; reserve them for properties you actually want computed lazily or validated, not as a generic replacement for variables.

### Summary — table

| Pattern | Syntax | When to use |
|---|---|---|
| Read-only computed | `function() { ... }` | Derived values that depend on other state |
| Read-write validated | `function(value) { if (missing(value)) ... else ... }` | Setters that enforce invariants |
| Hidden state | `env <- new.env(); env$.x <- ...` | Keep backing data out of the global env |
| R6 active field | `active = list(name = function(value) ...)` | OOP computed properties |
| Inspect | `bindingIsActive("name", env)` | Detect active vs normal binding |
| Remove | `rm("name", envir = env)` | Delete a binding |
