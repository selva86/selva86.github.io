## Practice Exercises (capstone, 3 exercises)

1. **Exercise 1 (medium):** Given `my_df` with columns `grp`, `x`, `y`, write a dplyr pipeline that filters to x > 0, groups by grp, and returns mean(y) and n per group, sorted descending by mean(y). Combine filter + group_by + summarise + arrange.

2. **Exercise 2 (hard):** Fit `lm(mpg ~ wt + hp + factor(cyl))` on mtcars, then write a function `my_predict_tidy(model, new_data)` that returns a tibble with predictions and 95% confidence intervals. Combines modelling + tidy output + function writing.

3. **Exercise 3 (hard, scenario):** You're given a 100,000-row data frame `my_big_data` with user_id, timestamp, event_type. Write code that (a) counts distinct events per user, (b) finds users with more than 50 events, (c) returns their most recent event. Combine dplyr grouped ops + n_distinct + arrange + slice.
