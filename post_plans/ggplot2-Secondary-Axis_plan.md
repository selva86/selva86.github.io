## C. Full Section Outline

### Lead sentence
`sec_axis()` adds a secondary y-axis (or x-axis) to a ggplot2 plot by applying a mathematical transformation to the primary axis — it does not create an independent axis.

### Introduction plan
- Hook: You have two variables on very different scales (temperature in Celsius and rainfall in mm) and want both on one plot. ggplot2 can do this, but it requires understanding why dual axes are constrained.
- What: sec_axis() and dup_axis() functions, how transformation works
- What you'll learn: build secondary axes, compute the transformation coefficient, style both axes, know when to use and when to avoid them
- Note: uses ggplot2 (loaded in first block)

### Core Content Sections (5 sections)

#### H2 1: "How does sec_axis() work?"
- Theory: sec_axis() transforms the primary axis scale; it doesn't plot a second variable independently. The transformation must be monotonic (strictly one-to-one).
- Code block 1: Basic sec_axis() with a simple transformation (~. * 1.8 + 32 for C-to-F)
- Callout: KEY INSIGHT — sec_axis() doesn't create an independent axis; it relabels the primary axis using a formula
- Inline exercise: Create a secondary axis that converts km to miles (~. * 0.621)

#### H2 2: "How do you compute the transformation coefficient?"
- Theory: When two variables have different ranges, derive a linear transformation y2 = a * y1 + b. Compute a = range(y2)/range(y1), b = min(y2) - a * min(y1). Then scale the second variable INTO the primary axis range and use the INVERSE to label the secondary axis.
- Code block 2: Step-by-step coefficient computation with economics dataset (unemploy + psavert)
- Code block 3: Plotting both variables with the computed transformation
- Callout: TIP — Always compute the scaling coefficient from data ranges rather than guessing a round number
- Inline exercise: Compute coefficient for mtcars mpg vs hp

#### H2 3: "How do you style a dual-axis plot so readers can tell which axis belongs to which line?"
- Theory: Color-code the axis title, labels, and line to match. Use theme() to style axis.title.y.left, axis.title.y.right, axis.text.y.left, axis.text.y.right
- Code block 4: Full styled dual-axis plot with color-coded axes
- Callout: WARNING — Without color-coding, readers cannot tell which line maps to which axis
- Inline exercise: Change the right axis color to "darkgreen" and match the line

#### H2 4: "When should you use a secondary axis (and when should you avoid it)?"
- Theory: Dual axes are appropriate for unit conversions (C/F, km/mi) and Pareto charts. They are misleading when two unrelated variables are overlaid — the visual correlation depends on the arbitrary scaling factor.
- Code block 5: Misleading example — change the coefficient and the visual "correlation" flips
- Callout: WARNING — Changing the scaling factor can make the same data look positively or negatively correlated
- Alternatives: facet_wrap(), separate plots with patchwork
- Inline exercise: Create a faceted alternative to the dual-axis plot

#### H2 5: "What are dup_axis() and secondary x-axes?"
- Theory: dup_axis() mirrors the primary axis (useful for top x-axis labels). sec_axis() works on x too via scale_x_continuous(sec.axis = ...).
- Code block 6: dup_axis() for a mirrored y-axis
- Code block 7: Secondary x-axis example
- Callout: TIP — Use dup_axis() when you want the same scale on both sides for easier reading of wide plots
- Inline exercise: Add a top x-axis that shows the same breaks

### Common Mistakes plan (3 mistakes)
1. Forgetting to scale the second variable into the primary axis range (plotting raw values — second variable is invisible or dominates)
2. Using a non-monotonic transformation in sec_axis() (error: transformation must be monotonic)
3. Mismatch between the data transformation and the axis transformation (axis labels don't match actual values)
