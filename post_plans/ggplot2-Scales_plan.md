## C. Full Section Outline

### Lead sentence
Scales control how ggplot2 maps data values to visual properties like position, colour, size, and transparency — and mastering them gives you complete control over every axis, legend, and colour palette in your plots.

### Introduction (## Introduction)
- Hook: Every time you write `aes(x = ..., y = ...)`, ggplot2 silently picks a default scale. Most of the time the defaults work. But when you need log axes, custom colour palettes, formatted labels, or exact axis limits — you need to take the wheel.
- What this article covers: the naming convention, position scales (continuous, discrete, log, date), colour/fill scales (brewer, manual, gradient, viridis), size/alpha scales, and the shared components (breaks, labels, limits, expand).
- We use base R, ggplot2, and the scales package. All code runs in your browser.

### Tail Sections

#### Common Mistakes (3-5)
1. Using limits instead of coord_cartesian() to zoom (data silently removed)
2. Using scale_size() instead of scale_size_area() for bubble charts (dishonest encoding)
3. Forgetting to load the scales package for label_comma(), label_percent(), etc.
4. Setting breaks as labels (breaks = c("A", "B") on continuous axis)
