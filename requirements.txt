# Python build dependencies for the Cloudflare Pages / GitHub build.
# Cloudflare Pages runs `pip install -r requirements.txt` before the build
# command (package.json "build": python _build/build_with_pagefind.py).
#
# Pygments powers build.py's static syntax highlighting: it Pygments-tokenizes
# the R inside every .webr-editor and wraps each line in <span class="cl">, so
# code shows COLOURED + LINE-NUMBERED on first paint (not only after the editor
# hydrates on click). build.py guards the import in try/except, so a missing
# Pygments silently ships monochrome code — which is exactly what happened on
# the CF build until this file existed. Pinned to match local build output.
Pygments==2.19.1
