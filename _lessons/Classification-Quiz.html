Question 1 of 6

Choosing k

In k-nearest-neighbours, increasing k tends to:

Correct: averaging over more neighbours steadies the boundary.
Too large a k washes out real structure and can hurt.
Question 2 of 6

The curse of dimensionality

As the number of features grows, the problem for distance-based methods like kNN is that:

Correct: in high dimensions distances concentrate, and the nearest neighbour is barely closer than the farthest.
Dimensionality does not change a feature's type.
Question 3 of 6

Why "naive"

The "naive" in Naive Bayes is the assumption that:

Correct: it multiplies per-feature likelihoods as if features never interact, which is rarely true but works well.
Balance is unrelated to the independence assumption.
Question 4 of 6

LDA versus QDA

LDA produces a straight (linear) boundary while QDA produces a curved one because:

Correct: a shared covariance gives a linear boundary; per-class covariances give a quadratic one.
Both use the class means; they differ on covariance.
Question 5 of 6

How a tree splits

A decision tree chooses each split by:

Correct: at each node it takes the locally best split, one node at a time.
It evaluates candidate splits and picks the most informative.
Question 6 of 6

Precision versus recall

Precision answers which question?

Correct: precision is true positives divided by all predicted positives.
Precision is about correctness of positive calls, not speed.
Run it: train a tree and read the matrix

A classifier and its confusion matrix

Run this to grow a decision tree on iris, predict the species, and lay the predictions against the truth.

RInteractive R
library(rpart) tree <- rpart(Species ~ ., data = iris) pred <- predict(tree, iris, type = "class") table(predicted = pred, actual = iris$Species)

  

  





The diagonal is correct calls; off-diagonal cells are the mistakes, and they show which species get confused.







Run it: turn the matrix into accuracy


One number from the matrix



Collapse the confusion matrix into a single accuracy score.

round(mean(pred == iris$Species), 3)

    

      
      
    

    

  

  





Accuracy is a fine summary here because the three species are balanced; on skewed classes you would reach for precision and recall instead.
