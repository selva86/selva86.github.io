Question 1 of 8

Single bracket, double bracket

You have a list x. What is the difference between x[1] and x[[1]]?

Right. Single bracket keeps the list box; double bracket reaches inside and hands you the contents.
[[ ]] works on any list element, of any type.
Question 2 of 8

What a data frame is

Which statement best describes a data frame?

Correct. That is why one column can be numbers and another text, while every column shares the same number of rows.
Columns can be any type, including text and factors.
Question 3 of 8

A tibble is a data frame, plus

A tibble differs from a base data.frame in which way?

Right. Tibbles also keep subsetting predictable, returning a tibble rather than dropping to a vector.
Tibbles are the native data frame of the tidyverse.
Question 4 of 8

What str() is for

You are handed an unfamiliar object. What does str(object) show you?

Correct. str() is the fastest way to see what something actually is before you work with it.
str() prints text, not a chart.
Question 5 of 8

Matrix versus data frame

You need a structure where every cell is the same type, laid out in rows and columns. Which fits?

Right. A matrix is one type throughout; reach for it when the whole grid is numbers, say.
A plain vector has no row-and-column layout.
Question 6 of 8

Converting text to numbers

You run as.numeric(c("12", "3.5", "abc")). What comes back?

Correct. The convertible strings become numbers; "abc" becomes NA and you get a warning.
Conversion happens; only the genuinely non-numeric value fails.

[[ ]] and $ both reach inside the list and hand you the actual element, here a string and a numeric vector you can take the mean of.
