Quiz

You have framed a problem as machine learning, met the bias-variance tradeoff, learned how data leakage sneaks in, and built a first end-to-end model. This quiz checks what stuck. The last two steps are live R you can run.

Question 1 of 6

What makes it supervised

A problem counts as supervised learning when:

Correct: supervised learning maps inputs to a known target observed in the training data.
Supervised learning works with numeric or categorical features.
Question 2 of 6

Reading the gap

A model scores 0.99 on the training set but 0.70 on the test set. This is a classic sign of:

Correct: it memorised the training data and fails to generalise.
More training would widen the gap, not close it.
Question 3 of 6

Spot the leak

Which step leaks information and inflates your score?

Correct: the scaler saw the test rows, so test performance is optimistic. Fit preprocessing on train only.
Picking the metric up front is good discipline.
Question 4 of 6

Why a held-out test set

You keep a test set you never tune on because:

Correct: once you tune on a set, its score is no longer unbiased, so the final test set stays untouched.
It estimates performance; it guarantees nothing.
Question 5 of 6

Pick the task

Predicting whether a customer will churn (yes or no) is a:

Correct: a categorical target (churn / no churn) is classification.
That compresses features; it does not predict a label.
Question 6 of 6

The accuracy trap

On a dataset where 99% of cases are negative, a model that always predicts "negative" scores 99% accuracy. The lesson is:

Correct: match the metric to the decision; accuracy hides failure on the rare class.
Imbalance is exactly why accuracy misleads here.
Run it: split before you model

A clean train/test split

Run this to split mtcars into train and test rows before any modelling, the order that prevents leakage.

RInteractive R
set.seed(1) n <- nrow(mtcars) train <- sample(n, round(0.7 * n)) cat("train rows:", length(train), " test rows:", n - length(train), "\n")

  

  





Splitting first means every later step (scaling, fitting) only ever sees the training rows.







Run it: score on the held-out rows


Honest evaluation



Fit on the training rows, then measure error on the test rows the model never saw.




  

    
RInteractive R

    
fit <- lm(mpg ~ wt + hp, data = mtcars[train, ])
pred <- predict(fit, mtcars[-train, ])
rmse <- sqrt(mean((mtcars$mpg[-train] - pred)^2))
round(rmse, 2)

    

      
      
    

    

  

  





That RMSE is an honest estimate because the test rows played no part in fitting.
