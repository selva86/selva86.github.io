Question 1 of 8

What aes() does

In a ggplot call, aes() is where you:

Correct: aes connects data to what you see.
Filtering happens before plotting, with dplyr.
Question 2 of 8

Points or a line

You plot one measurement per day over a year. Points versus a line:

Correct: lines suit ordered, continuous sequences.
For a trend over time the line reads far better.
Question 3 of 8

Layering geoms

ggplot(df, aes(x, y)) + geom_point() + geom_smooth() produces:

Correct: each geom is a layer, stacked in order.
Both layers render.
Question 4 of 8

Bar versus column

geom_bar() and geom_col() differ in that:

Correct: bar tallies, col plots given heights.
geom_bar computes the count itself.
Question 5 of 8

Histogram bins

Increasing the number of bins in geom_histogram():

Correct: more bins means finer detail, up to a point.
It is still a histogram of a continuous variable.
Question 6 of 8

Mapping versus setting

Putting colour = "blue" INSIDE aes() versus outside it:

Correct: aes is for data-driven aesthetics, not fixed values.
A constant setting adds no legend.
Run it: a scatter plot

Mapping two variables

Run this scatter of weight against mileage, then map color = factor(cyl) inside aes() and run again.

RInteractive R
library(ggplot2) ggplot(mtcars, aes(wt, mpg)) + geom_point()

  

  





Each point is a car; the downward drift shows heavier cars get fewer miles per gallon.







Run it: add a trend


Layering a smooth



Run this to add a linear trend line on top of the points. Each + adds a layer.




  

    
RInteractive R

    
library(ggplot2)

ggplot(mtcars, aes(wt, mpg)) +
  geom_point() +
  geom_smooth(method = "lm")

    

      
      
    

    

  

  





The fitted line summarises the relationship the points only hint at.
