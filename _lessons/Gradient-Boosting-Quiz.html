Question 1 of 6

How boosting builds

Gradient boosting builds its model by:

Correct: each new tree targets the residual (the gradient of the loss), correcting what is left.
It combines the trees; it does not pick just one.
Question 2 of 6

The learning rate

Lowering the learning rate (shrinkage) usually:

Correct: small steps mean each tree contributes a little, so you add more rounds but overfit less.
A small rate with enough trees often raises accuracy.
Question 3 of 6

Early stopping

Early stopping halts training when:

Correct: you stop where the held-out curve bottoms out, before it starts climbing again.
One tree is far too few; you watch the validation curve.
Question 4 of 6

The knobs that matter

Which trio of hyperparameters has the biggest effect in gradient boosting?

Correct: these three set how much the ensemble can learn and how fast.
Trees interact with the learning rate and depth; tuning one alone is not enough.
Question 5 of 6

Monotonic constraints

A monotonic constraint is useful when:

Correct: the constraint forces the model to honour a known, sensible direction.
Constraints make the response smoother and more predictable, not wigglier.
Question 6 of 6

Beyond a point estimate

A quantile regression forest is valuable because it gives you:

Correct: estimating quantiles turns a point forecast into an honest range that expresses uncertainty.
Quantile forests are about the spread of a numeric outcome.
Run it: boosting by hand

Five rounds of residual-fitting

Run this tiny boosting loop: start at the mean, then add five shallow stumps, each fitting what is left over. Watch the error fall.

RInteractive R
set.seed(1) x <- sort(runif(80, 0, 6)); y <- sin(x) + rnorm(80, 0, 0.2) library(rpart) pred <- rep(mean(y), length(y)); lr <- 0.3 for (i in 1:5) { resid <- y - pred stump <- rpart(resid ~ x, control = rpart.control(maxdepth = 1)) pred <- pred + lr * predict(stump) } round(sqrt(mean((y - pred)^2)), 3)

  

  





Each stump nudges the prediction toward the leftover signal; that sequential correction is boosting in one loop.







Run it: a prediction interval


A range, not a point



Quantiles turn a cloud of predicted outcomes into a 90% interval.




  

    
RInteractive R

    
set.seed(2)
draws <- rnorm(2000, mean = 12, sd = 3)
quantile(draws, c(0.05, 0.5, 0.95))

    

      
      
    

    

  

  





The 5th and 95th percentiles bracket the middle 90% of likely outcomes, exactly what a quantile model reports instead of a lone number.
