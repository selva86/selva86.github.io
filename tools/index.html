# reproduce in R
# Welch two-sample t-test from summary stats
m <- c(72.4, 76.6); s <- c(9.1, 8.7); n <- c(48, 51)
se <- sqrt(s[1]^2/n[1] + s[2]^2/n[2])
t  <- (m[2] - m[1]) / se
2 * pt(-abs(t), df = welch_df(s, n))   #> 0.021

A note from the desk

I built these because I was tired of pasting numbers into a calculator that hands back a p-value and nothing else. A bare number is not an answer, it is a thing you still have to defend. So every tool here insists on three things: the formula it used, the R code that reproduces it, and one plain sentence telling you what it actually means.

The widget above is the real t-test, not a screenshot. Change a mean, watch the verdict change with it. If a tool ever gives you a number you cannot explain to a colleague, that is a bug in my design, not a gap in your stats.

Calculators

8 toolsrun a test, get a number
t-Test Calculator: One-Sample, Two-Sample, Welch, Paired (Free Online) →

Free online t-test calculator. Run one-sample, paired, Welch's, and pooled two-sample t-tests on raw data or summary stats. Get t, df, p-value, 95% CI, and Cohen's d.

 A/B Test Calculator →

Free A/B test calculator. Sample size planning, two-proportion z-test, Bayesian beta-binomial (BF10), sequential sanity check, and lift CI. No signup required.

 Chi-Square Test Calculator (Independence, Goodness-of-Fit, Homogeneity) →

Free chi-square test calculator: independence, goodness-of-fit, and homogeneity. Standardized residuals, Cramer’s V, mosaic plot, and Fisher’s exact handoff.

 Confidence Interval Calculator →

Free confidence interval calculator: mean, proportion, difference, regression coefficient, Poisson rate, variance, correlation. Wilson, Clopper-Pearson, Newcombe, Welch, exact methods.

 Bootstrap CI Calculator →

Bootstrap confidence interval calculator: percentile, basic, and BCa for mean, median, SD, IQR, quantile, or any custom statistic. 10K+ resamples in your browser.

 P-Value Adjustment Calculator: Bonferroni, Holm, BH FDR, Benjamini-Yekutieli →

Adjust p-values for multiple comparisons: Bonferroni, Holm, Benjamini-Hochberg FDR, Benjamini-Yekutieli. Paste your p-values and see what stays significant. Free online.

 Equivalence / Non-Inferiority Calculator →

Plan and analyze equivalence and non-inferiority trials. Two one-sided tests (TOST), 90% CI vs equivalence bounds, and sample size calculation. Free online.

 Z-Score Calculator: Z to Percentile, Percentile to Z, Tail Probabilities →

Free z-score calculator. Convert raw scores to z, z to percentile, percentile to z, area between two z-values, and one or two-tailed tail probabilities.
