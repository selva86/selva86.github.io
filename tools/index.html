# reproduce in R
# Welch two-sample t-test from summary stats
m <- c(72.4, 76.6); s <- c(9.1, 8.7); n <- c(48, 51)
se <- sqrt(s[1]^2/n[1] + s[2]^2/n[2])
t  <- (m[2] - m[1]) / se
2 * pt(-abs(t), df = welch_df(s, n))   #> 0.021

A note from the desk

I built these because I was tired of pasting numbers into a calculator that hands back a p-value and nothing else. A bare number is not an answer, it is a thing you still have to defend. So every tool here insists on three things: the formula it used, the R code that reproduces it, and one plain sentence telling you what it actually means.

The widget above is the real t-test, not a screenshot. Change a mean, watch the verdict change with it. If a tool ever gives you a number you cannot explain to a colleague, that is a bug in my design, not a gap in your stats.
