Exercise 24: Compare ARIMA vs ETS



Difficulty: Advanced.



Show solution



  

    
RInteractive R

    
tr <- window(AirPassengers, end = c(1958,12))
te <- window(AirPassengers, start = c(1959,1))
f1 <- forecast(auto.arima(tr), h = length(te))
f2 <- forecast(ets(tr), h = length(te))

     ets   = accuracy(f2, te)[2,"RMSE"])
