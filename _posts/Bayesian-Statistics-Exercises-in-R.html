qbeta(c(0.025, 0.975), post_a, post_b)

Exercise 17: Grid approximation

Difficulty: Advanced.

Show solution 
p_grid <- seq(0, 1, length = 1000)
prior <- rep(1, 1000)
lik <- dbinom(7, 10, p_grid)
post <- (lik * prior) / sum(lik * prior)
sample(p_grid, 1e4, prob = post, replace = TRUE) |> mean()
