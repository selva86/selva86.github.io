Exercise 24: Loop over many parameters

Difficulty: Advanced.

Show solution 
for (r in c("US","EU","ASIA")) {
  rmarkdown::render("report.Rmd",
                    output_file = paste0("report_", r, ".html"),
                    params = list(region = r))
}
