Exercise 4.3: Validate strong passwords using multiple lookaheads

#> [1]  TRUE FALSE FALSE  TRUE  TRUE FALSE

Use str_detect() with stacked (?=.*...) lookaheads followed by .{8,}$ for the eight-character minimum.
