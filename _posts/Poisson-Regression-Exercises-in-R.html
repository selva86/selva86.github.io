Exercise 5: Test overdispersion



Show solution



  

    
RInteractive R

    
df <- tibble(x = 1:50, count = rpois(50, 5))
fit <- glm(count ~ x, data = df, family = poisson)
sum(residuals(fit, type = "pearson")^2) / fit$df.residual   # >1 suggests overdispersion
