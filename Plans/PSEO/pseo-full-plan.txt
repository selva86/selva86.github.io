A. Refined PSEO Category Structure

  Designed around three principles: (1) every page targets a distinct query
  with verified search demand, (2) each category is a template × dataset so
  production scales, (3) categories cluster cleanly under existing parent
  posts.

  14 categories, ~3,200 candidate pages → trim to ~2,000 for v1 list.

  #: 1
  Category: Function-deep (pkg × fn)
  Count: 900
  Template: signature → purpose → args → 4 ex → pitfalls → related → FAQ
  Parent cluster: Per-package parent (Data-Wrangling-With-dplyr,
    ggplot2-Tutorial, etc.)
  Why it wins: Highest exact-match volume; rivals rdocumentation.org which
    has weak content

  Quality bar (PSEO ≠ thin): every page has 800–1500 words, 1 runnable R
  block, 1 visual (chart, table, or diagram), 1 FAQ block, and 5+ internal
  links. Below that bar = don't publish.

  Demand validation gate (built into pipeline): before writing, automated
  check on:
  - Has ≥10 monthly searches (Google Suggest + AlsoAsked)
  - Top 10 SERP isn't dominated by Reddit/SO (means Google rewards full
  pages)
  - No existing post on r-statistics.co already covers it
  - Not a duplicate of a sibling PSEO

  B. Calculators (additive to existing 28)

  You have the cornerstones (t-test, chi-square, ANOVA via power, ROC,
  bootstrap CI, A/B test, Bayes factor, effect size, etc.). Net new = ~50 →
  78 total.

  Distribution probability (each its own page, PDF/CDF/quantile/sampler):
  - Normal · Binomial · Poisson · t · F · Chi-square · Beta · Gamma ·
  Exponential · Uniform · Lognormal · Weibull · Negative binomial ·
  Geometric · Hypergeometric (15)

  Inferential tests not yet covered:
  - Z-test · One-proportion · Two-proportion · Welch's t · Mann-Whitney U ·
  Wilcoxon signed-rank · Kruskal-Wallis · Friedman · McNemar · Fisher exact
  · Spearman ρ · Kendall τ · ANCOVA · MANOVA · Repeated-measures ANOVA (15)

  Power/sample size (one calculator per test family):
  - Survey sample size (proportion + FPC) · MDE for A/B · Two-proportion
  power · Correlation power · Cluster RCT power (5)

  Diagnostic & agreement:
  - Sensitivity/Specificity/PPV/NPV · Cohen's kappa · ICC · Cronbach's alpha
   · Bland-Altman (5)

  Effect size & interval extras:
  - Eta² / Omega² · Cliff's delta · Tolerance interval · Prediction interval
   · Quantile/IQR/5-number summary (5)

  Time series:
  - ADF / KPSS · Ljung-Box · Box-Cox lambda · ACF/PACF visual (4)

  Model selection:
  - AIC / BIC / AICc · WAIC / LOO · LR test (3)

  Visual sims (calculator-as-experience):
  - CLT animator · Bootstrap visualizer · k-fold CV simulator · MCMC
  convergence demo · Posterior updater · p-hacking simulator (6)

  Pages with Calculator in the URL slug rank 2–3× better than Tool for
  transactional queries — keep your URL pattern aligned (/calculator/X or
  X-calculator.html).

  G. Things You Need (Not Yet Asked)

  These are operational must-haves to ship 2,000 PSEO at quality without
  burning out:

  1. PSEO-specific skill (/write-pseo-v2): cuts /write-post-interactive's
  20–35 min to <8 min by skipping competitor analysis (templated), using a
  single canonical 800-word outline per category, 1 visual auto-rendered.
  2. Demand-validation pre-flight: a script that takes a candidate slug and
  rejects if (a) volume <10/mo, (b) SERP dominated by Reddit/SO, (c)
  duplicate of existing post. Saves 3–5 hours per dud.
  3. Batch generation orchestrator: queue 20 PSEO topics → parallel
  write-only (sequential publish per your no-parallel-agents memory) → stage
   for review → 1-click publish-batch.
  4. Sibling de-duplication index: programmatic-seo.json needs a top-level
  slug_registry to prevent two series from generating the same slug.
  5. Cluster-aware internal linking: PSEO siblings should auto-link to each
  other in a "Related" footer block, not just to the parent. Drives session
  depth.
  6. Schema markup auto-injection: HowTo, FAQ, SoftwareApplication, Course,
  BreadcrumbList. Already partial; needs systemic completion.
  7. Refresh cadence policy: every PSEO post auto-flagged for review at 12
  months. Package versions change; broken examples kill rankings.
  8. Quality gate for PSEO: Scripts/pseo_quality_check.py verifies 800+
  words, ≥1 code block, ≥1 visual, ≥5 internal links, FAQ present,
  demand-validated. Block publish if fails.
  9. Author the calculators as PSEO too: every calculator should ship with a
   1500-word companion explainer post. Calculator alone ranks for
  transactional intent; companion post captures informational. Doubles
  surface area.
  10. Production rate target: 2,000 PSEO at 5/day = 400 days. With 2 humans
  + skill = realistic. At 3/week = 12+ years. Pipeline throughput is the
  binding constraint, not idea count — invest in the skill before the list.
