## 07.2 Tasks per dataset (8)

For each dataset, write up to 8 task pages. Not every task applies to every dataset; ship only the ones that fit (e.g., time-series tasks only apply to AirPassengers, sunspots, BJsales).

Tasks:
1. EDA (always)
2. Visualization-Gallery (always)
3. Linear-Regression (where target is numeric)
4. Logistic-Regression / Classification (where target is binary or factor)
5. Clustering (where features support it)
6. PCA-or-Dimensionality-Reduction (where multi-feature)
7. Time-Series-Forecasting (where applicable)
8. Compare-with-Python-Pandas (always)
