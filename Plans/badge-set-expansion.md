# A badge set worth chasing

Plan. Asked for 2026-09-20: roughly double the collection, and make the
thresholds a challenge rather than a checklist.

Today the profile draws 16 ladder badges plus 6 track certificates, and the
ladder measures two things only: how many you have solved and how many days in
a row. The proposal below is **61 static badges across eleven dimensions**,
plus the 6 track certificates and the per-hub badges on top.

## The rule that shapes all of it

Every badge must be computable from data already recorded. `exercise_attempts`
carries more than the ladder has ever used:

```
hub_slug      which hub          -> breadth, hubs completed
hints_used    hints opened       -> unaided solves
xp_awarded    10 / 25 / 50       -> difficulty, since XP encodes it
submitted_at  unix seconds       -> hour of day, weekday, gaps
passed        first passes only  -> no attempt count exists
source        'backfill' or null -> anon-era solves banked at sign-in
```

So nine of the eleven dimensions need **no new capture at all**. The two that
do are called out at the end rather than quietly designed in. Nothing here is
awarded for something we cannot see, which is the same rule the certificate
work landed on yesterday.

## The eleven dimensions

### 1. Firsts (3, exist)
Off the Mark, Day One, Name on the Door.

### 2. Volume (9, extends the current 7)
The cricket scale, because it is the one counting vocabulary that already has
warmth in it and it lands exactly on the marks worth marking.

| solves | name |
|---|---|
| 5 | Off and Running |
| 10 | Double Digits |
| 25 | Quarter Century |
| 50 | Half Century |
| 100 | Century |
| 200 | Double Century |
| 300 | Triple Century |
| 500 | Five Hundred |
| 1000 | Four Figures |

### 3. Consistency (8, extends the current 3)
3, 7, 14, 30, 60, 100, 200, 365 days: Three Straight, Seven Straight,
Fortnight, Thirty Straight, Sixty Straight, The Long Run, Two Hundred Straight,
A Full Year.

Three days matters more than it looks. The current first streak rung is a week,
which is a long time to wait for a signal that showing up again counts.

### 4. Hubs completed (6) - new
Hat-Trick (3) and Five-For (5) carry the cricket line into a second dimension,
which is what makes the collection feel like one set rather than two lists.

| hubs | name |
|---|---|
| 1 | Clean Sweep |
| 3 | Hat-Trick |
| 5 | Five-For |
| 10 | Ten-For |
| 25 | Twenty-Five Up |
| 50 | Fifty Hubs |

### 5. Breadth, hubs touched (4) - new
5, 10, 25, 50 different hubs: Wandering Eye, Ten Doors, All-Rounder, Fifty Doors.
Rewards the opposite behaviour to dimension 4, deliberately. Some learners go
deep, some go wide, and only one of those is currently worth anything.

### 6. Difficulty (4) - new
Advanced exercises award 50 XP, so `xp_awarded = 50` identifies them with no
new column. 10, 25, 50, 100 advanced solves: Deep End, Tough Crowd, Heavy
Roller, Hundred Hard Ones.

### 7. Unaided (4) - new
`hints_used = 0`. 10, 50, 100, 250: No Help Needed, Unaided Fifty, Unaided
Hundred, Unaided Two-Fifty.

### 8. Cadence (5) - new
From `submitted_at`, and the most game-like of the set. These are the ones
people screenshot.

- **Dawn Raid** - a solve before 07:00 local
- **Night Shift** - a solve after 23:00
- **Weekender** - solves on both days of one weekend
- **The Return** - a solve after 30 clear days away
- **Double Shift** - 10 solves inside one day

### 9. Assessments (3) - new
Pass 1, 3, 6 of the eleven assessments: Examined, Thrice Tested, Six of Six.

### 10. Certificates (6, exist, dynamic)
One per track, already generated by `certBadges`.

### 11. Specials (3, exist)
No Residuals, First Cohort, Top of the Order.

**Static total: 3 + 9 + 8 + 6 + 4 + 4 + 4 + 5 + 3 + 3 = 49, plus 6 certificates
= 55 on the profile, with per-hub badges on top of that.** To pass 64 cleanly,
dimension 4 extends to 100 hubs and dimension 2 to 2000; both are reachable
only by someone who has genuinely worked the whole site, which is the point of
a top rung.

## Art

The cut-gem system shipped today carries this without changes. Each dimension
takes a hue, each tier takes a cut:

```
volume        amber      kite -> hex -> shield as the number grows
consistency   green      same progression
hubs          blue
breadth       blue, square cut, to read differently from depth
difficulty    violet
unaided       violet, square cut
cadence       amber, kite, small by design
```

A collector should be able to tell at a glance which dimension a stone belongs
to, and roughly how heavy it is, before reading a word.

## What needs new capture

Two ideas were cut for want of data rather than merit, and both are cheap to
add if wanted later:

- **First-try solves.** `exercise_attempts` stores first passes only, so there
  is no record of how many goes it took. Would need an attempts counter on the
  row.
- **Speed.** No elapsed time is stored per exercise. The hub badge records one
  in `badges_earned.meta_json`, so the shape exists; it just is not kept per
  solve.

## Order to build

1. Dimensions 2 and 3, extending ladders that already exist. Pure config.
2. Dimension 4, hubs completed, which reuses `hubProgress` from badges-hub.ts.
3. Dimensions 5, 6, 7, one query each over `exercise_attempts`.
4. Dimension 8, cadence, which needs care over timezones: "before 07:00" has to
   mean the learner's morning, not UTC.
5. Dimension 9, assessments, once `quiz_attempts` is actually being written to.

Steps 1 to 3 are a day's work and take the set from 16 to 44. Step 4 is where
the character is and deserves its own pass.

## One caution

Sixty badges only feel like a collection if they are visible as a set with gaps
in it. A grid of earned stones with the unearned ones greyed beside them is the
thing that pulls; a list of what you happen to have does not. The profile
already draws locked rungs with a progress bar, which is right. The dashboard
card shipped today shows earned plus the next one, which is right for a
dashboard. Neither should turn into a wall of sixty grey stones on day one, so
the profile should group by dimension and collapse the dimensions a learner has
not started.
