# Decision-Making and Communication: A Hands-On Interactive Course

<p class="lead">A result nobody acts on was not worth producing. The last mile of experimentation is a set of skills in its own right: framing a decision as a cost rather than a threshold, reporting a null honestly, and writing the thing up so that a product manager and an executive both take the same correct meaning from it.</p>

It begins by separating the two significances that get confused in every readout. A statistically significant result that is not worth shipping, and a non-significant one that is, shown with the effect size and the cost side by side so the distinction is arithmetic rather than rhetorical.

Then the reframe the course is built on. A ship decision is a loss function, not a threshold: the p-value is one input and the cost of being wrong in each direction is the rest. Bayesian A/B testing follows, computing the probability that B beats A, which is the quantity stakeholders have always believed a p-value gives them, with the prior made explicit rather than smuggled in.

Equivalence testing turns a null into a finding. Testing against a margin chosen in advance lets you report "no meaningful difference" as a result, which is both honest and far more useful to a roadmap than a shrug.

The rest is the craft of being believed. The structure of a readout and the one chart that earns its place. The same result told three ways without any audience being misled. What a trustworthy experiment review checks and in what order. What a hundred past experiments tell you that one cannot. And the ethics of running tests on people who did not volunteer, which is the lesson most curricula leave out.

Each lesson is a guided, interactive experience: you run real R in the page, drive live simulations, answer checkpoints as you go, and write code yourself. Nothing to install.

## Who this is for

Anyone who has to convert evidence into a recommendation and then defend it: product data scientists, analytics leads, and anyone who presents experiment results to people who will not read the appendix. [Bayesian Data Analysis](Bayesian-Data-Analysis-Course.html) goes deeper on the posterior machinery this course uses lightly. You should be able to read a confidence interval and fit a simple model.

## What you will be able to do

- Tell statistical significance from practical significance, with numbers
- Frame a ship decision as expected loss rather than a p-value threshold
- Compute the probability that the treatment beats control, and state your prior
- Run an equivalence test and report a null result as a finding
- Write an experiment readout with one chart and the caveats that belong
- Tell the same result to an engineer, a product manager and an executive
- Run an experiment review that blocks the launches that should be blocked
- Pool evidence across many past experiments into a prior worth holding
- Recognise an experiment that should not be run at all
